LiquidSlide — PowerPoint 液态玻璃插件 / Liquid Glass for PowerPoint

系统要求 / Requirements
- Windows x64 与 64 位桌面版 Microsoft PowerPoint
  Windows x64 and 64-bit desktop Microsoft PowerPoint
- .NET Framework 4.8
- Microsoft Edge WebView2 Evergreen Runtime 与支持 WebGPU 的显卡
  Microsoft Edge WebView2 Evergreen Runtime and WebGPU-capable graphics

安装、升级或卸载前，请保存演示文稿并关闭 PowerPoint。
Save presentations and close PowerPoint before installing, upgrading or uninstalling.

仅为当前用户安装，无需管理员权限。
Installation is per-user and does not require administrator privileges.

安装后打开 PowerPoint 的 LiquidSlide 选项卡，选择材质或打开面板。
Open the LiquidSlide ribbon tab in PowerPoint to access materials and the panel.

我的预设保存在本机；升级不会覆盖。清除 WebView2 用户数据会清除这些预设。
Personal presets are stored locally and kept during upgrades. Clearing WebView2 user data removes them.

此安装包未签名，不会自动下载系统依赖。
This installer is unsigned. Prerequisites are not downloaded automatically.
