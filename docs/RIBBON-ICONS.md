# Ribbon 图标来源

- `assets/经典通透.png`、`assets/白色玻璃.png`、`assets/黑色玻璃.png`、`assets/柔雾磨砂.png`：由项目维护者提供，按其指示直接用于插件；未修改原始文件。
- `assets/打开面板.png`、`assets/关于.png`：2026-09-08 使用 imagegen，根据上述四张图片生成的透明背景 PNG。前者以右侧栏表示面板，后者以信息符号表示关于。
- 六张图标作为资源嵌入 COM DLL，按原比例和 alpha 缩放到 Ribbon 的 32×32 画布，保留外围留白；面板四种材质按钮使用相同原始 PNG。

本次还将白色玻璃默认染色强度设为 0.6、柔雾磨砂设为 0.1。已有图形保存的参数不自动改写；重新选择预设时使用新默认值。
